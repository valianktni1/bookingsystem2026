# Phase 2B - Contract, booking form and website enquiries

## Supplied Weddings By Mark content now included

- Full Weddings By Mark agreement based on the supplied six-page contract
- Example couple, address, telephone, invoice and wedding details removed
- Existing temporary Phase 2B agreement automatically upgraded once
- Previously accepted agreements remain unchanged as permanent snapshots
- Client Wedding Booking Form matched to the supplied Studio Ninja questionnaire
- Address, couple, venue, time, package, payment-plan, guest-upload and music fields
- Submitted details update the correct booking and complete its workflow task

## Website enquiry form

- Public responsive form at `/enquiry`
- Designed for iframe use in WordPress/Elementor
- Automatic iframe height resizing on desktop and mobile
- Live package list from the editable booking-system catalogue
- New submissions create a Weddings By Mark enquiry and starter workflow automatically
- Optional SMTP acknowledgement email to the couple
- Honeypot and per-address submission throttling
- Embed code can be copied from **Packages & pricing** in the admin interface

The source contract wording should still be reviewed by the business owner or a qualified legal professional before production use. The software does not provide legal advice.
