# BookingSystem2026 V8.20 — Final Wedding Timings

V8.20 adds the approved Final Wedding Timings Form for native and imported
Weddings By Mark bookings.

- Five clear client steps: ceremony/reception, preparations/travel, running
  order, contacts/important details, and a live coverage check.
- Bronze / Package 1 includes four hours; Silver / Package 2 and higher include
  eight hours. A warning appears only beyond the included time plus 15 minutes.
- The standard start is at least one hour before the ceremony. Where the package
  has spare time and preparation travel is supplied, up to one spare hour can be
  used to recommend an earlier start without creating an overrun.
- The private admin run sheet highlights preparation/travel pressure and genuine
  overtime. The couple may see an overtime suggestion, but no charge, package,
  invoice or Calendar record is changed automatically.
- Submission creates one private review task. A later client update reopens it.
- The editable 30-day template now links straight to the timings form while
  preserving existing user edits such as the preferred telephone-call time.
- Studio Ninja imports keep their permanent general automation lock. The only
  exception is this Final Wedding Timings invitation, exactly 30 days before a
  wedding dated 21 October 2026 or later. No other Studio Ninja automatic email,
  reminder or client action is enabled.

Build: `2026.08.20-final-wedding-timings-v8.20`

No compose, environment or manual database change is required. Deployment does
not itself send email; the normal reminder scan applies the strict rules above.
