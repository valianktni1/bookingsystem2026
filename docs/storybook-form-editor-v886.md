# Storybook enquiry form editor

Go to **Storybooks → Edit enquiry form** to change the heading, introduction, send button and thank-you message. Add or hide stories and add optional or required questions for every story or just one. Preview is private and cannot send enquiries. Publish changes to update the public form at its existing web address.

The existing wedding and holiday options keep their usual questions. New stories use the standard book fields and need an agreed price when you create an invoice. Extra answers are shown on the order and included in the paid design brief. Changes apply to new public enquiries; existing orders keep their original story and extra answers. The main wedding photography enquiry form and the existing couple portal order form are separate.
