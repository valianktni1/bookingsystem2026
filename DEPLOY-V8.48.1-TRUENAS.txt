BookingSystem2026 V8.48.1 - TrueNAS deployment

First replace the GitHub Desktop repository contents with this release, commit,
and push main. Then paste the following commands into the TrueNAS shell:

cd /mnt/apps/dockge/data/bookingsystem2026

BOOKING_BACKUP="/mnt/apps/dockge/data/bookingsystem2026/bookingapp-before-v8481-$(date +%Y%m%d-%H%M%S).dump"

sudo sh -c "docker exec bookingsystem2026-db pg_dump -U bookingapp -d bookingapp -Fc > '$BOOKING_BACKUP'"

sudo test -s "$BOOKING_BACKUP"

sudo docker exec -i bookingsystem2026-db pg_restore --list < "$BOOKING_BACKUP" > /dev/null

sudo ls -lh "$BOOKING_BACKUP"

sudo docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml build --no-cache app

sudo docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml up -d app

sudo docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml ps

curl -fsS https://booking.weddingsbymark.uk/api/health && echo

Expected build:
2026.09.14-friendly-invoice-filenames-v8.48.1

Deployment does not migrate the database or send an email.
