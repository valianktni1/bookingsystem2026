BOOKINGSYSTEM2026 V8.7 - SAFE CUMULATIVE DEPLOYMENT

This release includes every feature and safety rule from V8.6.
It changes the application interface only. It does not reset or reseed the database.

1. Put the complete V8.7 contents in the main branch of:
   https://github.com/valianktni1/bookingsystem2026

2. Run these commands in the TrueNAS shell:

docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml down

docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml build --no-cache app

docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml up -d

3. Wait until the application is healthy:

docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml ps

curl -fsS http://127.0.0.1:30049/api/health

Expected build:
2026.08.05-guided-booking-workspace-v8.7

4. On the phone or computer, fully close the old booking-system tab and reopen:
   https://booking.weddingsbymark.uk

The 58 imported Studio Ninja weddings and all existing data remain in PostgreSQL.
Do not run any deletion, seed or import command for this deployment.
