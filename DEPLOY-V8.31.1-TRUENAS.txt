BookingSystem2026 V8.31.1 - TrueNAS deployment

1. Extract this complete ZIP over the GitHub working copy, commit and push it.
2. In the TrueNAS shell run:

cd /mnt/apps/dockge/data/bookingsystem2026

BOOKING_BACKUP="/mnt/apps/dockge/data/bookingsystem2026/bookingapp-before-v8311-$(date +%Y%m%d-%H%M%S).dump"

docker exec bookingsystem2026-db pg_dump -U bookingapp -d bookingapp -Fc > "$BOOKING_BACKUP"

ls -lh "$BOOKING_BACKUP"

docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml build --no-cache app

docker compose -f /mnt/apps/dockge/data/bookingsystem2026/compose.yaml up -d app

curl -sS http://127.0.0.1:30049/api/health

Expected build:
2026.08.28-enquiry-date-clash-v8.31.1

3. Hard-refresh the desktop browser. On a phone, close the booking-system tab completely and reopen it.
4. Open yesterday's enquiry. If its date already has a secured wedding, New Enquiries and the opened couple record will both show the private DATE BOOKED warning.
