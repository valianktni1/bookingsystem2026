# BookingSystem2026 V8.21 — Final Timings Records

V8.21 completes the administrator side of the Final Wedding Timings workflow.

- Before submission, Journey clearly says **Not submitted yet**.
- After submission, Journey shows **Form submitted** with the exact date/time.
- **View complete form** displays every answer supplied by the couple.
- **View / download PDF** opens a printable private run-sheet copy.
- Submission automatically creates one `Final Wedding Timings - Couple.pdf`
  document in the correct booking's Files tab.
- A later client update refreshes the same PDF instead of creating duplicates.
- The existing private review task is created or reopened as before.
- Studio Ninja automation suppression and the strict October cutoff are unchanged.

Build: `2026.08.20-final-timings-records-v8.21`

No compose, environment or manual database changes are required. Deployment
does not send any email or alter invoices, packages, payments or Calendar items.
