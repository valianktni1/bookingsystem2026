# Phase 2B — Packages, add-ons and client quotes

This update adds the Weddings By Mark package catalogue and pick-and-choose client quote flow.

## Included

- Bronze (£475 / £100 booking fee)
- Silver (£699 / £100 booking fee)
- Gold (£899 / £100 booking fee)
- Platinum (£1,299 / £150 booking fee)
- Ultimate (£1,699 / £150 booking fee)
- Six price-controlled add-ons with package eligibility rules
- Wedding album offer set to the latest supplied price of £120
- Fully editable package wording, prices, deposits, order and visibility
- Fully editable add-on wording, prices, order, visibility and package eligibility
- Mobile-optimised client package cards and live total calculation
- Immutable accepted quote snapshots so later catalogue edits do not rewrite old bookings
- Automatic booking update and invoice creation when a client accepts
- Separate package and add-on lines on generated invoice PDFs
- Protection against duplicate acceptance, unavailable extras and invalid package/add-on combinations

The contract, booking questionnaire and website enquiry form are intentionally not altered in this update.
