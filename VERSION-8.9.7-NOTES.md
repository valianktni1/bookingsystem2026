# Version 8.9.7 — Editable Website Enquiry Form

This is a complete cumulative release containing every feature through V8.9.7.

## What is new

- A dedicated **Web enquiry form** page under **Setup**.
- Edit the main heading, introduction, payment choices, submit button and thank-you message.
- Add short answers, long answers, choice lists and tick boxes.
- Rename, reorder, hide/show and change required/optional questions.
- Delete custom questions safely; previous enquiries keep their original answers.
- Essential workflow fields are protected against removal or incompatible field types.
- **Preview live form** opens exactly what couples see.
- **Copy website code** is now kept with the form editor instead of Packages & pricing.
- **Save & publish** updates the existing `/enquiry` iframe immediately.
- The iframe code already on the website does not need to be replaced.
- Each enquiry snapshots the exact question wording and answer submitted at that time.
- Website enquiry answers appear inside the booking’s **Forms & agreement** area.

## Safety

- Existing bookings, invoices, Studio Ninja records, mail, forms and documents are untouched.
- Imported Studio Ninja clients remain manual-only; no emails or reminders are enabled.
- Google Calendar remains untouched.
- Accepted quotes and historic enquiry answers are never rewritten when the form changes.
