# BookingSystem2026 V8.53 — Personal Studio Polish

This is a deliberately low-risk usability release for Mark's personal booking
system. It improves everyday navigation and search without changing business
rules or live data.

## Improvements

- Mobile navigation now keeps Home, Enquiries, Weddings and Inbox one tap away.
- The fifth mobile action opens the complete existing menu.
- The Inbox icon mirrors the live unread-email count.
- Global search accepts names, email addresses, venues, invoice numbers and
  wedding dates, including UK `DD/MM/YYYY` dates.
- Client search results show the weekday, wedding date and venue.
- Mobile touch targets, text, dialogs, focus states and sticky navigation are
  easier to use during a working day.

## Protected behaviour

No invoice, Accounts integration, payment, Google Calendar, manual date block,
pay-later arrangement, contract, form, final-timings, email, SMS, follow-up,
client-portal or Studio Ninja import rule has been changed.
